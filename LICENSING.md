# Licensing

mercat is free software under the [GNU GPL v3.0 or later](LICENSE).
If you can live with the GPL, use it. You don't need to ask me.

## Using mercat in your product

The GPL has one big catch for businesses: if you ship mercat inside your
software, you ship your source code too.

If that doesn't work for you, **a commercial license is available.** You
build mercat into your product, and your code stays yours. Contact me for
details.
