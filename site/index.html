Mermaid diagrams, drawn in your terminal.

Your agent digs the plan. mercat shows you the tunnels.

Try your own diagram ↓

Install with Homebrew

brew install tawago/tap/mercat

Then, in Claude Code

/plugin install mercat --marketplace tawago/mercat

Try your own diagram

Paste Mermaid, or pick an example. Drag the terminal’s right edge to change its width; mercat redraws to fit, just like mercat -w 80.

10px
mercat80 columns

The same diagram in two other terminal renderers

Same source, same 80-column terminal (the dashed line). mermaid-ascii gets the same width limit as mercat; beautiful-mermaid has no width option, so it draws at its natural size.

mermaid-asciicommit 5a9df15
Loading mermaid-ascii…

beautiful-mermaid1.1.3
Loading beautiful-mermaid…

Everything runs in your browser; nothing is sent anywhere. mermaid-ascii and beautiful-mermaid are MIT-licensed projects by their own authors, run here unmodified: each uses its default settings, and mermaid-ascii also gets the width limit.
