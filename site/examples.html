Install

One binary for macOS and Linux. The Claude Code plugin calls the same mercat you install here. Every release is on the releases page.

Homebrew

Works on macOS and Linux, and puts mercat on your PATH for the plugin.

brew install tawago/tap/mercat

Claude Code plugin

Inside Claude Code, at its prompt. What the plugin does.

/plugin install mercat --marketplace tawago/mercat
Other ways to install

Debian, Ubuntu, Fedora and RHEL

.deb and .rpm packages are attached to each release. Put the release’s version in place of <version>:

sudo apt install ./mercat_<version>_amd64.deb
sudo dnf install ./mercat-<version>.x86_64.rpm

From source

Requires Zig 0.17.0+. In a clone of the repository:

zig build -Doptimize=ReleaseFast# Binary at ./zig-out/bin/mercat

Installer script

curl -fsSL https://raw.githubusercontent.com/tawago/mercat/main/install.sh | bash
